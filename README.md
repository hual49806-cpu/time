# 時光修復局－國語版 V2

## GitHub Pages 手機部署
請把 ZIP 解壓縮後的所有檔案，上傳到 repository 根目錄。

根目錄必須直接看到：
- index.html
- style.css
- game.js
- .nojekyll
- assets
- data

圖片資料夾固定為：
- assets/background
- assets/boss
- assets/characters

請勿改成 backgrounds 或 bosses。

## 網址
https://你的帳號.github.io/儲存庫名稱/

若更新後仍看到舊畫面，可在網址後加：
?v=2
